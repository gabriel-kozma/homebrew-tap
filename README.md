# homebrew-tap

Homebrew formulae for my tools.

## Install

```sh
brew install gabriel-kozma/tap/mac-agent-jail

Or tap first, then install by name:

brew tap gabriel-kozma/tap
brew install mac-agent-jail

Formulae

┌────────────────┬──────────────────────────────────────────────────────────────────────────┐
│    Formula     │                               Description                                │
├────────────────┼──────────────────────────────────────────────────────────────────────────┤
│ mac-agent-jail │ Run AI coding agents in a macOS Seatbelt sandbox confined to the project │
└────────────────┴──────────────────────────────────────────────────────────────────────────┘

macOS only. The formula builds from source, so Homebrew installs Rust as a build dependency.

Updating

brew update
brew upgrade mac-agent-jail

Formula/mac-agent-jail.rb is generated by the release workflow in the main repository on each v* tag. Do not edit it here; changes belong in packaging/homebrew/mac-agent-jail.rb there.

Report problems at https://github.com/gabriel-kozma/mac-age

Commit it as `README.md` on the default branch. The installil the first `v*` tag publishes the formula.
